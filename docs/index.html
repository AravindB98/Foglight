Foglight

All-seeing internet intelligence for agents and humans — pluggable channels, persistent memory, temporal knowledge.

View on GitHub ▶ Try the Demo

🧒 What is this? (Plain English)

Imagine hiring a tireless assistant who watches the internet for you — news sites, feeds, forums — remembers everything it sees, and can answer 'what changed since last week?' Foglight is that assistant for both humans and AI agents: it watches, remembers over time, and serves what it learned through clean interfaces.

✨ Key Features

Pluggable channels

News, feeds, forums — add a connector, gain a sense.

Persistent memory

What it saw last month is still queryable today.

Temporal knowledge graph

Facts carry timestamps; change becomes visible.

Agent-ready

Serve fresh world-knowledge to AI agents via clean APIs.
